# Employee Management System in C

## Project Description

This mini-project consists of developing an employee management system using the C programming language.

The program allows the user to manage employee information through a menu. Different operations are available, including adding, displaying, modifying, and deleting employee records.

The program also performs basic salary calculations, such as income tax (IR), net salary, total payroll, and average salary. Employee information can also be saved to a file and loaded when needed.

## Main Functions

The program provides the following operations:

* Add an employee
* Display the list of employees
* Modify an employee
* Delete an employee
* Calculate the total payroll
* Calculate the average salary
* Calculate income tax (IR)
* Calculate the net salary
* Save employee information to a file
* Load employee information from a file

## Employee Information

The program manages the following information for each employee:

* ID
* First name
* Last name
* Date of birth
* Gender
* Gross salary
* Income tax (IR)
* Net salary
* Marital status
* Education level
* Number of children

## Technologies Used

The project was developed in **C** using basic programming concepts such as structures, arrays, functions, loops, conditions, and file handling.

The main source code is available in `src/employe.c`.

## Project Objective

The objective of this mini-project is to apply the fundamental concepts of C programming to a practical case of employee management.
